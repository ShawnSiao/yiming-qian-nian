# R15 公开试用版

版本：`r15-preview.1`。日期：2026-10-23。

[打开试用](https://shawnsiao.github.io/yiming-qian-nian/versions/r15/?view=play&score=zhuzhi-ci-recording) · [R14 试用版](https://shawnsiao.github.io/yiming-qian-nian/versions/r14/?view=play&score=zhuzhi-ci-recording) · [旧版首页](https://shawnsiao.github.io/yiming-qian-nian/)

## 本版内容

- 修复误减为四口钟的问题，每个音组保留 C–B 七口正鼓钟位。桌面整架 21 口，手机按空间显示 7 或 14 口；竖屏仅折行，不删钟。
- 保留手绘图中 C/E、D/F、G/B、A/下一组 C 的配对。图中未说明的 E/E、F/F♯、B/B 沿用原方案；左右侧鼓同音，敲击部位分别记录。
- 音名采用 c¹、c²、c³ 等小字组写法，内部 MIDI 和实际音高不变。切换覆盖 C3–C7 自然音及各组 F♯，不是全半音覆盖。
- 《晴天》的 F♯ 对应 F 钟侧鼓，可按原调试听和跟奏；旧作品保留原始音高、时间及已记录的钟位。
- 保留 main 的三种钟体、铜饰音牌和漆木架；放大铜槌并加强短时落点反馈。
- 宽屏曲谱栏可左右换位、拖动调宽；手机使用紧凑谱条。支持看谱自由演奏、试听和跟奏。
- 「竹枝词 · 简版」保留原有 30 秒主题；「竹枝词 · 完整版」为 153 秒录音转谱初稿，可试听全程。
- 单钟 3D 观赏按需载入，支持旋转、缩放、内腔和剖视。

## 验证与边界

本版保留六组确定性测试：音位／记谱、演奏／触区、交互／音频、移动视口、全长转谱和曲谱工作台。Actions 在部署前运行测试，并检查运行资源完整性。本地浏览器十组尺寸均保留完整七钟音组，147 次实际点击的音高与部位检查通过；这些检查不等于 iPhone／Android 真机、听感、温升或音乐准确性验收。

完整版仍有 54 处候选击音待核对，未完成专家逐音听校；其余音符也未独立审定。不能把它作为审定的编钟／编磬双声部总谱。

原音对照来自项目所有者提供的《竹枝词》音频，仅在主动播放时载入；源 WAV、录音分析缓存、研究照片、Blender 源文件和测试截图不在此版本中。现代编配及录音的公开分发授权尚未独立核验，不将此次试用部署视为权利状态确认。

## 来源与许可

演奏图片及绘制语言沿用本仓库 main `20b716d`。模型为馆藏照片参考的项目自建模型，不含参考照片像素，不是扫描、CT、测绘或声学仿真复原。铜槌是现代交互设计，不作为历史演奏工具的考证结论。

React／ReactDOM 18.3.1、Three.js r180 及其辅助模块使用仓库内副本；许可证保留在 `vendor/REACT-LICENSE.txt`、`vendor/THREE-LICENSE.txt`。项目代码使用根目录 MIT 许可证；第三方曲目及录音的权利说明单独保留。

GitHub Actions 同时保留 R14、本版运行文件和旧版静态入口。`version.json` 标识固定版本；部署时生成的 `deployment.json` 记录对应 Git 提交。后续版本使用新的版本目录，避免替换本试用路径。
