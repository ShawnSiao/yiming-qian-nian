# R14 公开试用版

版本：`r14-preview.1`。日期：2026-10-23。

[打开试用](https://shawnsiao.github.io/yiming-qian-nian/versions/r14/?view=play&score=zhuzhi-ci-recording) · [旧版首页](https://shawnsiao.github.io/yiming-qian-nian/)

## 本版内容

- 每排七口钟，按空间显示 7、14 或 21 口，可切换 C3–B6。
- 保留 main 的三种钟体、铜饰音牌和漆木架；放大铜槌并加强短时落点反馈。
- 宽屏曲谱栏可左右换位、拖动调宽；手机使用紧凑谱条。支持看谱自由演奏、试听和跟奏。
- 「竹枝词 · 简版」保留原有 30 秒主题；「竹枝词 · 完整版」为 153 秒录音转谱初稿，可试听全程。
- 单钟 3D 观赏按需载入，支持旋转、缩放、内腔和剖视。

## 验证与边界

本版保留五组确定性测试：演奏／触区、交互／音频、移动视口、全长转谱和曲谱工作台。Actions 在部署前运行测试，并检查运行资源完整性。宽屏、手机横竖屏的本地浏览器检查不等于 iPhone／Android 真机、听感、温升或音乐准确性验收。

完整版仍有 54 处候选击音待核对，未完成专家逐音听校；其余音符也未独立审定。不能把它作为审定的编钟／编磬双声部总谱。

原音对照来自项目所有者提供的《竹枝词》音频，仅在主动播放时载入；源 WAV、录音分析缓存、研究照片、Blender 源文件和测试截图不在此版本中。现代编配及录音的公开分发授权尚未独立核验，不将此次试用部署视为权利状态确认。
