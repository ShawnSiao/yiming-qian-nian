# 一鸣千年

[English](README.md) | **简体中文**

在浏览器中观赏青铜编钟，试听一钟双音，并对照乐谱逐句演奏。

[**打开中文版**](https://shawnsiao.github.io/yiming-qian-nian/?lang=zh) · [English version](https://shawnsiao.github.io/yiming-qian-nian/?lang=en)

## 体验方式

- **先听双音**：轻敲首页 2D 大编钟的中央和侧边，比较两个音高；也可用 Enter／空格敲中央、左右方向键敲侧边。轻量入场不阻挡试听和导航。
- **逐句跟奏**：选择乐谱，先听示范，再敲亮起的击点。等待式练习敲对后才继续，节拍式练习按拍点进行。
- **手机演奏**：根据展示空间展示 4、8 或 12 口钟，每排始终四口。「聚焦一排」可以放大当前音组，也可展开音组、切换范围；切组不会改变谱音的实际音高。
- **看谱演奏**：宽屏在钟区旁展示乐谱，支持调整两区宽度和谱子位置；手机在钟区下方保留当前乐句。
- **保存钟曲**：录制落槌事件，保存时输入曲名，也可在「我的」修改名称和回放。保存内容是音符事件，不是麦克风录音或音频文件。
- **观察结构**：选择部位查看说明，钟腔使用预渲染剖面图。开启「3D」后可旋转、缩放、平移和实时剖视。说明附博物馆和研究资料出处。

界面提供简体中文和英文。首次访问根据浏览器语言选择，切换后保存偏好；链接参数 `?lang=zh` 和 `?lang=en` 优先。切换语言保留已保存钟曲，并暂停当前练习、保留进度。

## 音名与音域

中文版将 **C4/E4 显示为 c¹/e¹**、**C5/E5 显示为 c²/e²**，依次类推。英文版保留国际常用的科学音高记法，例如中央 C 写作 **C4**。这些显示方式不改变实际音高。

数字谱以 **1–7** 表示音阶级数；`1=C`、`1=F` 和 `1=G` 分别表示 1 对应 C、F 和 G。上下点表示八度变化，谱音下方的音名表示实际音高；没有对应击点的音仅供试听。

演奏状态栏的「音名 ⇄ 简谱」可切换钟上音牌和演奏提示。数字标注跟随当前曲谱调号，包括《竹枝词》完整版的 `1=F` 和《晴天》的 `1=G`。切换保留击区、声音、练习进度和录曲，继续使用原版金边小音牌及钟角悬挂位置。

每音组四口钟，采用以下现代演奏配对。左右钟角发出同一个侧鼓音：

| 正鼓 | 左右侧鼓 |
| --- | --- |
| C | E |
| D | F |
| G | B |
| A | 下一八度的 C |

可选音组覆盖 **C3–C7 的自然音**；从 C4 开始的三排提供 **C4–C7 共 22 个不同音高**，相邻音组共用边界 C。此布局不包含升 F 等变化音；相关曲目可按原音高试听，未设置的音不显示错误击点。含这些音的小节仅供试听，其余小节可以跟练，不删音或移调。四钟编排属于本项目的交互设计，不代表某套出土编钟的原始调律。

旧录曲沿用原存储标识，始终按已保存的 MIDI 回放。当前钟架存在对应音时显示匹配击点；没有击点时仍播放原音，不显示错误高亮，也不改写历史事件。

## 曲库

曲库包含入门练习、熟悉旋律，以及两个《竹枝词》版本：

- **简版**：依据提供的主题谱图整理，8 小节，约 30 秒，`1=C`。
- **完整版**：覆盖所提供的 2 分 33 秒演奏录音，`1=F`；附原音对照、MIDI、MusicXML 和可打印谱页。

完整版是合奏显著击音线的转谱初稿，尚未完成专家逐音听校，也未可靠分离编钟与编磬声部。**＊** 标记待核对击音，参考伴奏同样为转谱估计。编配和第三方曲目涉及独立权利，见[来源与素材说明](docs/credits.md)。

**《烟花易冷 · 谱图选段》**依据提供的简谱正文录入，`1=C`，4/4，77 BPM，含 2 拍弱起与 28 个完整小节，约 89 秒。支持整段示范和逐句跟奏，保留休止、连音与倚音。前奏含当前四钟音组未设置的音，未纳入选段；图片未显示完整结尾与反复终点，因此按主谱线演奏一遍，不标为整曲完整版。

**《晴天》**依据提供的两页简谱录入，`1=G`，4/4，67 BPM，含前奏共 69 小节，原调试听约 4 分 06 秒。保留休止、高低音点、倚音、延音和小节内变化音。含 F♯、C♯、D♯ 的小节在当前钟架上仅供试听；末段 X 没有固定音高，保留分组作为节奏参考，旋律试听在 X 段前结束。

## 声音、存储与模型边界

声音默认开启；浏览器可能要求首次点击后才允许发声。可在音量控件调节大小，并在交互后重听落钟。演奏音和落钟音由程序合成，不是博物馆实物录音。页面遵循减少动态效果偏好，静止或进入后台时停止相应渲染。

**新开页面和刷新均默认关闭 3D。** 首页和观赏页使用当前模型离线渲染的图片，不下载 GLB、Three.js，也不创建 WebGL。开关只影响这两页，选择仅保留在本次页面内。准备 3D 时，2D 钟仍可操作；30 秒内未就绪、WebGL 不支持或上下文丢失时恢复 2D，并提供重试。进入演奏页后可继续下载模型数据，离开模型页则释放 GPU 场景。切换展示模式保留音量、试听进度及正在衰减的钟声。各图片独立加载，WebP 失败后尝试 PNG；两者失败仍有可敲击的本地钟形占位。

钟曲、音量和语言偏好保存在当前浏览器。应用没有业务后端、麦克风采集、账户系统或分析埋点；沿用 R14、R15 的钟曲存储标识。清除站点数据、更换浏览器或设备可能使原记录不可用。首次加载页面和素材需要网络，当前未提供离线缓存安装。

3D 模型根据照片制作，用于科普展示。比例、壁厚、纹饰和重绘铭文字形不是考古测绘复原；剖视属于结构示意，未进行声学模拟。

## 本地运行

使用 Node.js 24 或更新版本，无需安装依赖或打包：

```sh
node scripts/serve.mjs
```

打开 [http://127.0.0.1:4312/app/](http://127.0.0.1:4312/app/)。预览服务显式配置 JavaScript MIME 类型，兼顾 Windows 的 `.mjs` 加载。

```sh
node tests/i18n.mjs
node tests/current-model.mjs
node tests/home-arrival.mjs
node tests/mobile-viewport.mjs
node tests/practice.mjs
node tests/workspace.mjs
node tests/paired-pitches.mjs
node tests/numbered-notation.mjs
node tests/yanhua-yi-leng.mjs
node tests/resource-loading.mjs
node scripts/build-pages.mjs
node tests/pages.mjs
```

浏览器回归使用开发依赖 Playwright，不进入应用部署产物：

```sh
npm ci
npx playwright install --with-deps chromium firefox webkit
npm run test:browser
```

Windows 下还检查已安装的 Chrome、Edge。报告明确记录不可用的浏览器或音频能力；手机尺寸模拟与 WebKit 测试构建不等同于真实 iPhone Safari、Android Chrome 或原故障电脑的 Edge 验收。

构建仅重建生成目录 `_site/`。PR 运行校验；合并至 `main` 后，由 GitHub Actions 将产物部署到 GitHub Pages。设计稿、Blender 源文件、原始 WAV 和验证输出不进入部署产物。
